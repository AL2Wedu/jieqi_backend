# jieqi_backend(节气种田 · 后端)

教育 + AI + 模拟经营游戏的后端仓库(元创S营项目)。客户端使用 Godot 4,后端为独立部署的 API 服务。

## 技术栈

- FastAPI + PostgreSQL(+pgvector)+ Redis
- 大模型 LLM(DeepSeek / 通义千问 / 智谱)+ RAG 知识库
